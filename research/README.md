# Исследование каталога площадок

Здесь лежат исходные данные каталога очных занятий: организации, их филиалы по
городам и ссылки на страницы, где эти сведения были найдены.

## Зачем это в репозитории

Прототип содержал семьдесят «мастер-классов» с адресами вида
«Аэроклуб „Взлёт“, ул. Авиационная, 3» и ссылками на `example-vzlet.ru`.
Ни одной такой организации не существует. Чтобы это не повторилось, каталог
собирается из файлов исследования, а не пишется руками, и каждая запись
хранит ссылку на источник.

Правило простое: **адрес указывается только тогда, когда он подтверждён на
сайте самой организации.** Пустое поле честнее правдоподобного вымысла.

## Файлы

| Файл | Что внутри |
|---|---|
| `state-networks.json` | Государственные сети: «Кванториум», «IT-куб», региональные центры модели «Сириус», дома научной коллаборации |
| `it-schools.json` | Школы программирования и робототехники: Coddy, «Пиксель», «Лига Роботов», «Академия ТОП», «Яндекс Лицей» и другие |
| `creative-schools.json` | Дизайн, графика, медиа и звук; плюс региональные порталы «Навигатор дополнительного образования» |
| `niche.json` | Дроны, киберспорт, биоинженерия; отдельно — всероссийские программы и олимпиады |
| `links-report.md` | Отчёт о замене выдуманных ссылок на онлайн-курсы |
| `niche-notes.md` | Рабочие заметки по нишевым направлениям |

## Как пересобрать каталог

```bash
npm run venues      # research/*.json → src/data/venues.js
npm run seed        # заливка в базу
npm run test:links  # проверка, что все ссылки живые
```

Сборщик (`scripts/build-venues.js`) отбраковывает домены-заглушки, приводит
названия городов к справочнику, отсеивает организации «18+» и сверяет ключи
направлений с учебным контентом.

## Что учесть при обновлении

* Российские государственные порталы (`*.навигатор.дети`, `mos.ru`,
  региональные домены образования) часто не отвечают на запросы из зарубежных
  сетей. `npm run test:links` помечает такие случаи предупреждением, а не
  ошибкой — их адреса подтверждались документами профильных ведомств.
* Возраст и цены берутся из формулировок организации. Если цену найти не
  удалось, в каталоге стоит «Платно» без числа.
* Поле `verified` означает, что страница филиала была открыта и прочитана.
  Записи с `verified: false` показываются без отметки «проверено».
